# Curation Pipeline

Choose the authority before writing.

For HMK-native memory:

1. ingestion and normalization
2. related retrieval
3. curation decision
4. canonical HMK write
5. optional isolated HMK projection

For LLM Wiki knowledge:

1. stage raw evidence and curated note
2. publish through the wiki protocol gate
3. index the authoritative wiki files in HMK
4. verify the provenance edge and receipt

Possible outputs:

- only `evidence`
- `evidence` + links
- `evidence` + `library` note
- authoritative LLM Wiki publication + HMK retrieval index
- `evidence` + map note

The complete authority and drift rules are in
[`memory-ownership-contract.md`](memory-ownership-contract.md).
